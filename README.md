# 謎の目的地ナビ

条件に合う行き先を選び、到着まで名前を隠して案内するNext.jsアプリです。

## 環境構築

Node.js 24.xとnpmを使用します。

```sh
npm ci
npm run dev
```

http://localhost:3000/setup で現在地のOpenStreetMapを確認し、乗り物・時間・ジャンルを選んで経路を準備します。「冒険開始」から「GPSナビを開始」を押してください。スマートフォンではHTTPS接続が必要です。

```sh
npm run lint
npm run typecheck
npm test
npm run build
```

## 採用する技術構成

| 機能 | 技術 | APIキー |
|---|---|---|
| 地図データ | OpenStreetMap | 不要 |
| 地図表示 | MapLibre GL JS | 不要 |
| タイル | OpenFreeMap公開サービス | 不要 |
| 道路経路 | OSRM（FOSSGIS公開自動車サービス） | 不要 |
| 観光地検索 | OpenStreetMap Nominatim（予備: Overpass API） | 不要 |
| GPS | Geolocation API | 不要 |
| 矢印 | 自作NavigationEngine | 不要 |
| 音声 | Web Speech API | 不要 |
| 到着判定 | 自作ArrivalDetector | 不要 |

OSRM・MapLibreはOSSです。公開サービスの継続提供や無制限利用を保証するものではありません。経路要求は同一サーバープロセス内で約1.1秒以上の間隔を取り、候補評価は最大5件です。

地図設定は[OpenFreeMap公式ガイド](https://openfreemap.org/quick_start/)、経路変換は[OSRM API仕様](https://project-osrm.org/docs/v5.7.0/api/)に基づきます。地図上の帰属表示を維持してください。

MapLibreのWorkerはNext.js開発中のハッシュ付きURLへ依存しないよう、バージョンを固定したファイルを`public/vendor/`から同一オリジン配信します。追加の環境変数は不要です。MapLibreを更新する場合はWorkerファイルも同じバージョンへ更新してください。地図表示にはWebGL2対応ブラウザとOpenFreeMapへの接続が必要です。

## 観光地と経路データ

冒険作成APIは利用者の操作時に現在地周辺の実在地点をOpenStreetMap Nominatimから1回検索し、候補ごとにOSRMの道路経路を取得します。Nominatimが応答しない場合のみOverpass APIを予備検索に使います。固定の架空地点、直線、模式図へフォールバックしません。公開サービスが応答しない場合や実道路経路が見つからない場合は、エラーとして条件の変更・再試行を案内します。

所要時間は片道・渋滞非反映、指定時間の許容誤差は±15分、候補評価は最大5件です。現在地周辺の検索範囲はNominatimまたは予備のOverpassへ、現在地と候補地点はOSRMへ送信され、地図表示時にはOpenFreeMapへ通信します。OpenStreetMap登録内容だけでは営業時間・駐車場入口・立入条件を保証できないため、到着後も現地の案内を優先してください。

## ナビと到着判定

OSRMが返す道路形状へGPS位置を投影し、経路上の進捗、次の案内、残距離、残時間を計算します。PCのWi-Fi測位も考慮し、ナビ案内には精度200m以内・測位60秒以内の位置情報を使用します。経路から大きく外れた場合は誤案内を避けるため案内と読み上げを停止し、地図確認を促します。自動再探索は未実装です。複雑な交差点では道路標識と現地状況を優先してください。

GPS精度50m以内、測位から15秒以内を有効とし、目的地50m以内の測位が1秒以上空けて2回連続すると到着を確定します。15秒を超える測位間隔は連続判定をリセットします。到着確定後はGPS監視と音声を停止し、名称・説明・OpenStreetMap地点情報を公開します。到着前の`/arrived`直接表示では目的地を公開しません。

ナビ開始時は目的地名を伏せた冒険モードです。「ルートを確認」では目的地位置が分かる可能性を警告した後、既存のMapLibre地図にOSRM道路形状と現在地を表示します。切り替えでも同じ経路・ナビ状態を維持します。

音声は初期OFFです。対応ブラウザでONにすると案内地点の約300m前と約80m前で日本語を一度ずつ読み上げます。端末の音声エンジンに依存します。中断・エラー・到着・画面移動時にGPS監視または音声を停止します。到着公開は誤判定を避けるため従来どおり精度50m以内・測位15秒以内の位置情報を2回確認します。ブラウザを閉じた状態、バックグラウンドでの安定した動作、写真の自動取得は未対応です。経路はメモリにのみ保持し、再読み込みで破棄します。目的地非表示は演出であり、通信・内部状態から座標を秘匿する仕組みではありません。

自動車とバイクを選択できます。ただし、公開OSRMでは専用のオートバイプロファイルを使用できないため、バイク選択時もOpenStreetMapを基にした自動車プロファイルの実道路経路を使用します。二輪車固有の通行禁止、排気量区分、細かな規制は反映されません。これは架空経路ではありませんが、二輪専用ナビではないため、必ず道路標識と現地規制を優先してください。

公開Nominatim・OSRMとの実通信とブラウザでのWebGL地図表示は確認済みです。スマートフォン実機でのGPS・音声と実道路走行は未検証です。自動テストは合成応答と位置サンプルで検証します。

## 環境変数

標準構成では.envの設定もAPIキーも不要です。.env.exampleは任意設定・旧実装用の変数名だけを記載しています。

| 名前 | 用途 |
|---|---|
| GOOGLE_MAPS_API_KEY | 残してある旧Googleアダプター専用。現在の標準経路では未使用 |
| NEXT_PUBLIC_APP_URL | 将来の公開URL用。現在未使用 |
| OSM_NOMINATIM_URL | 任意のNominatim検索接続先。未指定時はOSMF公開HTTPSエンドポイントを使用 |
| OSM_OVERPASS_URL | 任意の予備Overpass API接続先。未指定時は公開HTTPSエンドポイントを順に使用 |

旧Googleアダプターとデモ用フィクスチャは既存の単体テスト互換性のため残していますが、利用者向けの冒険作成API・画面からは呼びません。
