# サンプル（プロダクト名）

## 開発を始めるには

現在は仕様策定段階で、アプリケーションと起動コマンドは未実装です。
リポジトリをcloneし、[開発仕様書](SPEC.md)と[作業ルール](AGENTS.md)を確認してください。
アプリの初期構築時に、必要なランタイムのバージョン、依存関係のインストール、環境変数の設定、起動・動作確認の手順をここに追記します。

### 環境変数（実装予定）

| 変数名 | 用途 | 必要となる条件 |
| --- | --- | --- |
| `GOOGLE_MAPS_API_KEY` | サーバー側の経路API呼び出し | Google Routes API連携を利用する場合 |
| `NEXT_PUBLIC_APP_URL` | アプリの公開URL | 実装時に用途・要否を確定 |

現時点で使用中の環境変数はありません。デモモードはAPIキーなしで動作する設計です。
実際の値はローカルの環境ファイルやデプロイ先の環境設定で管理し、コミットしないでください。
環境変数を実装に追加するときは、変数名と空値のみの `.env.example` も用意してください。

### GitHub運用

- `main` へ直接pushせず、機能ごとのブランチとPull Requestを作成します。
- 変更はレビュー可能な単位に分けます。
- Issueには「何を」「なぜ」「完了条件」を記載します。
- `.env`、APIキー、秘密鍵、個人情報はコミットしません。
- 環境構築手順や環境変数名を変更したら、このREADMEも更新します。値は記載しません。

Issue・PR作成時には、リポジトリに用意したテンプレートを使用してください。
