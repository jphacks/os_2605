# 謎の目的地ナビ

条件に合う行き先を選び、到着まで名前を隠して案内するNext.jsアプリです。

## 環境構築

Node.js 24.xとnpmを使用します。

```sh
npm ci
npm run dev
```

http://localhost:3000/setup で乗り物・時間・ジャンルを選び、位置情報を許可して経路を準備します。「冒険開始」から「GPSナビを開始」を押してください。スマートフォンではHTTPS接続が必要です。

```sh
npm run lint
npm run typecheck
npm test
npm run build
```

## 採用する技術構成

| 機能 | 技術 | APIキー |
|---|---|---|
| 地図データ | OpenStreetMap | 不要 |
| 地図表示 | MapLibre GL JS | 不要 |
| タイル | OpenFreeMap公開サービス | 不要 |
| 道路経路 | OSRM（FOSSGIS公開自動車サービス） | 不要 |
| 観光地 | data/real-spots.json | 不要 |
| GPS | Geolocation API | 不要 |
| 矢印 | 自作NavigationEngine | 不要 |
| 音声 | Web Speech API | 不要 |
| 到着判定 | 自作ArrivalDetector | 不要 |

OSRM・MapLibreはOSSです。公開サービスの継続提供や無制限利用を保証するものではありません。経路要求は同一サーバープロセス内で約1.1秒以上の間隔を取り、候補評価は最大5件です。

地図設定は[OpenFreeMap公式ガイド](https://openfreemap.org/quick_start/)、経路変換は[OSRM API仕様](https://project-osrm.org/docs/v5.7.0/api/)に基づきます。地図上の帰属表示を維持してください。

MapLibreのWorkerは`new URL(..., import.meta.url)`でビルド対象に含め、アプリの`/_next/static/`から配信します。ライブラリの既定の相対URLには依存しません。手動でのWorkerコピーや追加の環境変数は不要です。地図表示にはWebGL2対応ブラウザとOpenFreeMapへの接続が必要です。

## 観光地データ

実在スポットはdata/real-spots.jsonで管理し、架空のdata/spots.jsonとdata/demoRoutes.jsonはデモ専用です。現時点では滋賀の道の駅びわ湖大橋米プラザ・白鬚神社・メタセコイア並木の3件です。各データに公式観光案内のsourceUrlを記載しています。座標は施設付近の目安で、駐車場入口・営業時間・立入条件は実地未確認です。accessVerifiedはfalseのまま保持しています。

所要時間は片道・渋滞非反映、許容誤差は±15分です。登録地域やジャンルが限られるため条件に合う候補がない場合があります。現在地・目的地をOSRMに送信し、地図表示時にはOpenFreeMapに通信します。標準の観光地選択は外部検索を行いません。

## ナビと到着判定

次の案内地点付近30mに入ると案内を進めます。案内地点までの表示距離は直線距離です。曲がり角を通り過ぎた場合の復帰・自動再探索・道路への位置補正は未実装です。複雑な交差点では道路標識と現地状況を優先してください。

GPS精度50m以内、測位から15秒以内を有効とし、目的地35m以内の測位が5秒以上続くと到着を表示し、名称・説明・公式案内を公開します。15秒を超える測位間隔は到着判定をリセットします。

音声は初期OFFです。対応ブラウザでONにすると案内地点150m以内で日本語を読み上げます。端末の音声エンジンに依存します。中断・画面移動時にGPS監視と音声を停止します。ブラウザを閉じた状態、バックグラウンドでの安定した動作、二輪専用経路、自動デモナビ、写真の用意は未対応です。経路はメモリにのみ保持し、再読み込みで破棄します。目的地非表示は演出であり、通信・内部状態から座標を秘匿する仕組みではありません。

実機でのGPS・音声・WebGL地図表示、公開OSRMとの実通信、実道路走行は未検証です。自動テストは合成応答と位置サンプルで検証します。

## 環境変数

標準構成では.envの設定もAPIキーも不要です。.env.exampleは任意設定・旧実装用の変数名だけを記載しています。

| 名前 | 用途 |
|---|---|
| GOOGLE_MAPS_API_KEY | 残してある旧Googleアダプター専用。現在の標準経路では未使用 |
| NEXT_PUBLIC_APP_URL | 将来の公開URL用。現在未使用 |
| OSM_OVERPASS_URL | 残してある外部検索関数の接続先。標準のJSON選択では未使用 |

旧Googleアダプター・Overpass検索関数は互換性のため残していますが、標準の冒険作成APIから呼びません。
